A native offline music player for Apple silicon Macs running macOS 27 or later. It plays local audio files and supports library browsing, playback queues, listening history, and synchronized lyrics.

![MUZIKA? Now Playing with synchronized lyrics](docs/now-playing.png)

## Installation

Download the app archive from the repository’s Releases page. Unzip it and move the app to Applications.

## Usage notes

Add music folders under **Settings → Local Library**. Synchronized lyrics can be embedded in audio files or stored in adjacent `.lrc` files.

In **Now Playing**, timed lyrics fill progressively between timestamps. Lyrics without timestamps scroll with playback and reach the bottom when the track ends. The spectrum visualizer next to the audio format shows the track's live frequency levels.
